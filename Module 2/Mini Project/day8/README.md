# Day 8 Mini Project — TeleBirr Transaction Report

A report generator over a list of TeleBirr transactions using `map`, `filter`, `reduce`, destructuring, spread, and modules.

## 📁 Modules

| File | Responsibility |
|------|----------------|
| `transactions.js` | Exports the transaction data |
| `report.js` | Exports summary functions |
| `app.js` | Imports and prints the report |

## 🚀 Usage

```bash
node app.js
