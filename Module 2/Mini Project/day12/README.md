# 🌤️ Weather App

A simple weather app that fetches current weather data from a free API.

## 🚀 Features

- Search for any city
- Displays: temperature, condition, humidity, wind speed, feels like
- Loading state
- Error handling
- Responsive design

## 📁 Files

| File | Responsibility |
|------|----------------|
| `index.html` | HTML structure with Tailwind CSS |
| `app.js` | JavaScript logic |
| `README.md` | This file |

## 🔗 API Used

- [goweather.herokuapp.com](https://goweather.herokuapp.com/weather/{city})

## 🎯 How to Run

1. Open `index.html` in a browser
2. Enter a city name
3. Click **Search** or press **Enter**
